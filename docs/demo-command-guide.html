Run the six fixed modes

Run in order. The identity step is local. Each live result includes its UTC timestamp. Correlate each HTTP result with Access or Gateway logs in the same time window; a 302 alone does not prove the Worker rejected a request.

Evidence to check

  1. For the three private API requests, compare Access deny, deny, allow decisions with the CLI's 403, 403, 200 responses.
  2. For the safe send, find a Gateway allow and an accepted controlled-endpoint event.
  3. For the protected send, find a Gateway DLP block and no accepted controlled-endpoint event in a bounded window.
